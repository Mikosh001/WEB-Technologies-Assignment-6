# Assignment 6 jQuery

Student: Berdibek Meiirbek  
Group: SE-2528

A separate page for each jQuery task, connected by a shared navigation bar.
The project uses HTML, one CSS file, and one short jQuery script per task.

## Run locally

Open index.html in a browser. Internet access is required to load jQuery from
the official CDN. No package installation or build step is needed.

Alternatively, run python -m http.server 8000 in this directory and open
http://localhost:8000/ in your browser.

Task 0 uses $(document).ready() and prints the exact message
"jQuery is ready!" in the console.

Task 2 includes Hide, Show, and Toggle to demonstrate all three required methods.
Task 5 includes Add Item, Prepend Item, and Remove Item to demonstrate
.append(), .prepend(), and .remove().

Task 11 completes the Accordion Menu option. Opening one section closes the
other sections. Native buttons support mouse and keyboard interaction.

Animations can be repeated. Clicking an animation button again restarts it.
The full jQuery 3.7.1 build is loaded from https://code.jquery.com/jquery-3.7.1.min.js
with an integrity hash. The slim build is not used because the tasks need effects.
